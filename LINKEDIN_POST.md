# Collecty — Turn any website into structured data

I built a tool that takes the messy web and turns it into clean, structured spreadsheets.

Meet Collecty: a web scraping assistant that lets you point at a URL, define the columns you want, and get back a ready-to-use CSV. No boilerplate code, no xpath puzzles, no copy-pasting rows one by one.

What it does:
- Crawl multiple pages from a starting URL
- Extract exactly the fields you care about
- Auto-format values consistently across every row
- Export straight to CSV

Under the hood it uses Groq LLMs for fast, intelligent parsing and includes API-key rotation so long jobs keep running smoothly.

I have been using it to pull product data, build lead lists, and compare pricing across sites in minutes instead of hours.

If you do any kind of market research, competitive analysis, or data collection, this is built for you.
